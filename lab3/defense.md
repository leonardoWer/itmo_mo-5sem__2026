# Памятка для защиты лабораторной работы № 3

**Что решается в работе?** Ищутся наименьшее и наибольшее значения квадрата расстояния до точки (1, −2) при движении по единичной окружности.

**Что такое допустимая точка?** Точка, удовлетворяющая ограничению x² + y² = 1. Например, (1, 0) допустима, а (0, 0) — нет.

**Почему нельзя просто решить grad f = 0?** Это дало бы точку (1, −2), но она не лежит на окружности: сумма квадратов координат равна 5. Для условной задачи нужно учитывать ограничение.

**Зачем нужен множитель λ?** В экстремуме градиенты f и h параллельны. Множитель позволяет записать это условие как grad f + λgrad h = 0. Поэтому в точке экстремума изменение f вдоль касательной равно нулю.

**Почему метод применим?** Обе функции гладкие, допустимые точки существуют, а квадрат длины градиента ограничения на окружности равен 4. Ранг Якобиана равен числу ограничений, то есть 1.

**Можно ли сразу делить на 1 + λ?** Только после проверки λ = −1. Этот случай даёт 0 = 1, поэтому он невозможен, и деление не теряет решений.

**Почему найдено ровно два кандидата?** Уравнение (1 + λ)² = 5 имеет два корня. Каждый однозначно определяет x и y; других случаев нет.

**Доказывает ли система Лагранжа глобальность?** Сама по себе нет. Здесь оба экстремума существуют на компактной окружности, все точки регулярны и все кандидаты найдены. Поэтому их сравнение доказывает глобальность. Ещё есть прямая оценка 6 − 2√5 ≤ f ≤ 6 + 2√5.

**Почему у строго выпуклой f есть условный максимум?** Допустимое множество — окружность, а не круг; оно невыпукло. Строгая выпуклость f на плоскости не запрещает максимум на окружности. Например, середина точек (1, 0) и (−1, 0) не лежит на окружности.

**Что проверяет программа?** Она строит L, производные и систему, решает её, проверяет все корни подстановкой, считает невязки, ранг Якобиана и значения f. Готовый ответ в код не записан.

**Что означает EPS?** Допуск для численной проверки равенств. Это не шаг алгоритма и не точность координат. В данном решении равенства подтверждены точно.

**Если решатель вернул семейство?** Его надо исследовать целиком. Нельзя подставить один параметр и объявить найденными все экстремумы. Численный поиск из одной начальной точки также может пропустить другие корни.

**Что изменится при другом ограничении?** Для двух равенств нужны два множителя и линейная независимость двух градиентов. При неравенствах рассматриваются условия Каруша — Куна — Таккера, включая знаки множителей и дополняющую нежёсткость.
